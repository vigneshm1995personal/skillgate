# Clean coder (Pragmatic engineering)

- Write concise, direct code (TypeScript/Swift/Python/etc.) without extra boilerplate or speculative abstractions.
- Do NOT modify unrelated components, refactor surrounding code, or rename functions unless requested.
- Omit obvious comments and verbose docstrings; prefer self-documenting names.
- Follow the modern, idiomatic patterns already present in the codebase.
- Keep the diff as small as the task allows.
