# Frontend design (anti-AI-aesthetic guardrail)

- Follow the project's design tokens strictly (tokens file or CSS variables); don't invent new colors, radii, or spacing.
- Avoid generic AI patterns: purple-on-white gradients, default Inter everywhere, uniform rounded cards, emoji decoration.
- Purposeful typography and an explicit color system with intentional contrast.
- Add meaningful micro-interactions; keep layouts responsive and accessible (keyboard, focus states, contrast).
- Reuse existing components before creating new ones.
